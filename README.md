# Family Chiropractic Querétaro — Demo conceptual

Demo estática creada a partir del sitio público y del alcance técnico cotizado. Permite presentar visualmente:

- Rediseño responsive orientado a conversión.
- Nueve rutas clínicas y testimonios segmentables.
- Módulo Tormenta Perfecta / Scans INSiGHT.
- Flujo simulado de agenda, anticipo y confirmación en Atlas.
- Asistente virtual Pixie en modo demostración.
- Integración del equipo clínico, contacto, horarios y ubicación.

## Ejecutar localmente

No requiere instalación. Abre `index.html` o inicia un servidor estático:

```bash
python -m http.server 4173
```

Luego visita `http://localhost:4173`.

## Importante

Este prototipo es una demostración comercial. Atlas, Stripe/Mercado Pago, WhatsApp Business y Pixie aparecen como flujos simulados; su integración productiva requiere credenciales, permisos y validación técnica.
